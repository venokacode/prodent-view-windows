# ProDENT View Privacy Policy

Effective date: July 13, 2026

ProDENT View is provided by VENOKA USA INC. This policy explains how the Windows application handles information.

## Information handled by the app

ProDENT View lets users enter patient-related details such as a name, chart identifier, phone number, email address, and notes. It also captures, imports, organizes, displays, deletes, and exports dental camera images. Users should enter only information they are authorized to handle.

## Local storage

Patient records, images, and application data are stored locally on the Windows PC under the current user's profile. The app does not upload patient information or images to VENOKA USA INC or to a cloud service.

## Camera access

The app accesses a user-selected compatible UVC camera to provide live preview and capture images. Camera content is processed locally.

## Diagnostics

Users may choose to export a local diagnostics text file for troubleshooting. It can include Windows and app versions, machine name, camera device details, capture route, local storage paths, and record counts. The app does not transmit this file automatically. Users decide whether to share it with support and should review it before sharing.

## Network activity, analytics, and advertising

The current version does not require an account, does not perform cloud synchronization, does not include advertising, and does not send telemetry or analytics.

## User control and retention

Users control the local records and images. Image deletion uses the Windows Recycle Bin where available. Uninstalling the app does not automatically delete user-created records or images. Users can remove retained data from `%LOCALAPPDATA%\ProDENT\ProDENT View` when it is no longer needed, subject to their organization's retention requirements.

## Security

Because the data is stored on the user's PC, users and organizations are responsible for Windows account security, device access controls, backups, and compliance with applicable privacy and healthcare requirements.
