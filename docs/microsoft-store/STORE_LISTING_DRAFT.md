## Product Name

ProDENT View

## Short Description

Preview and capture images from compatible UVC intraoral cameras, then organize and export them locally on your Windows PC.

## Description

ProDENT View is a focused Windows desktop app for compatible UVC intraoral cameras. It lets you preview a connected camera, capture still images, import existing images, organize images by patient and date, review them, move selected images to the Recycle Bin, and export copies to a folder you choose.

Patient details and images are stored locally on the Windows PC. ProDENT View does not require an account, does not upload patient information or images, and does not include cloud synchronization or advertising. Camera access is used only for live preview and image capture initiated by the user.

## What's New

Initial Microsoft Store release with UVC camera preview, still-image capture, preview-frame fallback, local patient and image organization, import, review, Recycle Bin deletion, export, and diagnostics export.

## Product Features

- Preview compatible UVC intraoral cameras
- Capture still images with automatic fallback when needed
- Organize images locally by patient and date
- Import and review existing images
- Export selected images to a user-chosen folder
- Move selected images to the Windows Recycle Bin
- Export local diagnostics for troubleshooting

## Certification Notes

ProDENT View is a local-only UVC intraoral camera preview and capture utility. No login is required. Connect a compatible USB UVC camera, select it in the camera list, select or create a test patient using non-identifying sample data, and click Capture. The app stores data under `%LOCALAPPDATA%\ProDENT\ProDENT View`. It makes no network requests. Please do not use real patient data during certification.
