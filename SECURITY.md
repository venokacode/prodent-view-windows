# Security Policy

## Reporting Sensitive Issues

Do not report patient-identifying data, private support uploads, API keys,
signing material, or confidential device logs in public GitHub issues.

For sensitive reports, contact the private ProDENT support or security channel
published by ProDENT.

## Public Issues

Public issues should include only non-sensitive reproduction details:

- Windows version
- app version or commit
- camera model and UVC behavior
- non-sensitive logs or screenshots
- expected and actual behavior

Use synthetic or anonymized data for screenshots and sample files.
